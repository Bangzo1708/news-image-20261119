"19 November 2026: The World in One Day" — one image summing up Thursday 19 November 2026's world news. The entry image (entry.png, 1024×1024, under 1 MiB) is written to the output directory by main.ts, which then re-reads what it wrote and refuses to finish unless the copy is byte-for-byte identical, the right size, the right dimensions, and a whole image file. No network, no randomness, no image library — every check is done by hand on the raw bytes, so the two graded runs can only ever produce the same file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
